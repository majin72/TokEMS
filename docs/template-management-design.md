# TokEMS 模板管理工作台设计约束

## 1. 视觉主题与氛围

模板管理延续 TokEMS 冷白纸面和编辑型排版，整体是高密度、克制、可核对的运营工作台。页面通过步骤、状态和真实预览建立信任，装饰只服务于当前任务。

## 2. 色彩与角色

- 画布：`var(--surface)`，承载页面背景。
- 主要表面：`#fff`，承载表单、文档和预览。
- 品牌蓝：`var(--blue)`，用于主操作、当前步骤和已绑定变量。
- 成功绿：`var(--green)`，用于扫描通过和已保存状态。
- 告警金：`var(--gold)`，用于需要人工确认的扫描变化。
- 危险红：`var(--red)`，用于阻塞项和失败状态。

## 3. 字体规则

- 页面与面板标题使用现有宋体栈 `var(--serif)`。
- 正文、表单和操作使用系统中文无衬线 `var(--sans)`。
- 摘要、节点 ID、变量路径和版本使用 `var(--mono)`。
- 页面标题 32px，工作区标题 20px，正文 13px，技术辅助信息 10px。

## 4. 组件样式

- 按钮沿用 4px 圆角与 40px 最小点击区域，按压反馈为 `scale(0.96)`。
- 表单控件使用白底、1px 分隔线和清晰焦点环。
- 步骤轨道用编号圆点、短连接线和文字状态表达进度。
- 扫描报告使用连续列表，阻塞项、告警和自动修复拥有独立语义色。
- 变量映射使用列表与预览双栏，选中变量时同步突出对应节点。

## 5. 布局原则

- 模板列表保持高密度资料表结构，来源类型进入第一层识别信息。
- 新建模板使用独立路由，四步依次为选择来源、上传扫描、变量确认、创建完成。
- HTML 编辑工作台采用 280px 变量栏、弹性预览区和 320px 属性栏。
- 所有页面保持 4px 间距网格，主要分组使用 16px、24px 和 32px。

## 6. 深度与层级

- 相邻区域优先使用背景色阶和 1px 分隔线。
- 预览画布使用现有小型阴影，表达浏览器页面悬浮于工作台。
- 操作确认和任务结果留在页面内，不新增通用模态框。

## 7. 实施边界

- 保留现有后台导航、色彩令牌、按钮和表单语言。
- HTML 原文只显示为纯文本下载信息。
- AI 建议始终显示来源、置信度、理由和待应用状态。
- 阻塞项存在时禁用创建与发布操作。
- 空状态提供明确下一步，错误显示在产生问题的步骤附近。

## 8. 响应式行为

- 1280px 以上展示完整三栏工作区。
- 820px 以下将属性栏移动到预览下方，变量栏保持可横向滚动的列表。
- 560px 以下步骤轨道改为紧凑编号，操作按钮按阅读顺序纵向排列。
- 所有操作保持至少 40px 点击区域，375px 与 320px 宽度不产生页面横向溢出。

## 9. 交互标识

- 上传后自动进入扫描，并逐步显示解析、净化、资源和变量识别结果。
- 规则建议默认选择置信度不低于 0.95 的项目，用户可以逐项取消。
- 点击变量建议会定位并突出预览节点，点击预览节点会筛选相关建议。
- 保存后状态文字固定占位，避免工具栏在“未保存”“保存中”“已保存”之间跳动。
