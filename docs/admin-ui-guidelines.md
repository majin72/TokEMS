# TokEMS 后台界面规范

## 视觉方向

TokEMS 后台采用冷白纸面、编辑型排版和低饱和功能色。页面优先帮助运营人员确认当前大会、识别状态和完成任务，装饰保持克制。

## 字体与字号

- 品牌与一级、二级标题使用宋体系统栈。
- 正文、导航、表单和按钮使用系统无衬线字体。
- 编号、日期、快捷键、状态计数和数据标签使用系统等宽字体。
- 页面标题为 30 至 34px，面板标题为 20px，导航与主要正文为 13px。
- 表格正文为 12px，说明文字为 11px，等宽微标签的下限为 10px。
- 中文正文行高使用 1.65 至 1.75，数字列启用等宽数字。

## 色彩与层级

- 页面画布使用 `--surface`，主要内容容器使用白色。
- 主行动和当前状态使用 `--blue`，危险、成功、等待状态分别使用红、绿、金语义色。
- 相邻区域通过背景色阶、1px 分隔线和留白建立层级。
- 卡片阴影仅用于需要脱离画布的重点表面。

## 间距与圆角

- 间距基于 4px 网格，常用值为 8、12、16、20、24、32px。
- 控件默认高度为 42px，紧凑操作也保留至少 40px 点击区域。
- 输入框和按钮使用 4px 圆角，结构容器使用 6px 圆角，浮层可使用 8px 圆角。

## 交互状态

- 所有交互元素提供可见的蓝色键盘焦点。
- 按压反馈统一使用 `scale(0.96)`，过渡时长为 160ms。
- 搜索在当前上下文内完成，支持键盘快捷键和 Enter 提交。
- 移动端导航使用抽屉，支持遮罩点击与 Esc 关闭。抽屉打开后，焦点进入导航；关闭后，焦点返回触发按钮。隐藏状态不能进入键盘顺序。
- 状态文案使用清晰中文，等宽英文只用于辅助标签和技术标识。
- 删除、停用、退款、回滚和下架使用危险操作样式，并在影响较大时增加确认步骤。
- 涉及多个字段或需要核对上下文的业务操作使用页面内表单，不能依赖浏览器原生输入弹窗。
- 加载、成功和失败信息使用对应的可访问状态语义，表格提供隐藏标题，表单控件提供可识别名称。

## 响应式

- 820px 以下切换为移动端导航抽屉，主内容保持单栏。
- 560px 以下筛选器、表单和操作组按阅读顺序纵向排列。
- 宽表格可以保留横向滚动；发票等任务型列表在 560px 以下转为带字段标签的信息卡，按钮、状态和关键数字完整展示。
- 每次界面调整需要覆盖全部后台路由，检查 1440px 桌面端和 390px 窄屏，并验证长中文、长邮箱和英文路径。
- 自动回归检查字号下限、页面横向溢出、移动端点击区域、表单名称和新窗口链接安全属性。
